# 책 기반 Agent 개선 — 이어서 시작하기

마지막 갱신: 2026-10-06 (KST)

## 목표와 진행 방식

『Build an AI Agent (From Scratch)』를 현재 프로젝트와 연결해 배우고,
필요한 개선을 이유와 함께 설계·구현한다.

사용자 우선순위(2026-10-01): **기존 자동 리포트 개선을 먼저 진행하고, 대시보드의 대화형 기능은 후속 확장으로 둔다.**
현재 작업 범위에 챗봇 UI·대화 메모리·대화용 도구 호출은 포함하지 않는다.
자동 리포트의 고정 워크플로는 유지하며, 필요한 경우 특정 분석 단계에 제한된 자율성을 추가할 수 있다.
챗봇은 인터페이스이고, 에이전트 여부는 모델이 도구와 다음 행동을 선택하는 실행 구조로 구분한다.

**지정한 독서 범위의 완독 여부 확인 → 프로젝트 적용 또는 다음 독서 안내**를 반복한다.
적용이 필요하면 읽은 내용과 현재 코드의 연결을 짧게 설명하고, 작은 범위로 설계·구현·검증한다.
모든 독서 범위마다 코드 수정이나 퀴즈를 할 필요는 없다.

## 다음 세션

> docs/agent-improvement/CURRENT.md 보고 책 기반 에이전트 개선 이어가자.

1. 이 파일에서 완료한 범위와 다음 독서 범위를 확인한다. 필요한 대화 근거만 [누적 기록](LEARNING_LOG.md)에서 확인한다.
2. 사용자가 새 진도를 말하지 않았다면 **지정 범위를 다 읽었는지 먼저 묻고 답을 기다린다.**
   “다 읽음”이라는 보고는 현재 지정 범위의 완독으로 반영하며 같은 확인을 반복하지 않는다.
   “어디 읽어야 하지?”처럼 진도 안내만 요청했다면 지정 범위를 바로 알려 준다.
3. 답에 따라 다음처럼 진행한다.

| 독서 상태 | 다음 행동 |
|---|---|
| 아직 안 읽음 | 현재 지정 범위와 멈출 지점을 짧게 안내한다. 코드 적용이나 퀴즈부터 시작하지 않는다. |
| 일부 읽음 | 알려 준 위치를 기록하고 남은 범위를 안내한다. 사용자가 읽은 부분의 적용을 요청하면 그 범위에서 진행한다. |
| 다 읽음 + 지금 적용할 부분이 있음 | 읽은 개념이 해결할 현재 코드의 문제와 작은 변경 범위를 설명하고 적용으로 이어간다. 필요한 설계 선택만 질문하며, 이미 정한 범위를 다시 승인받지 않는다. |
| 다 읽음 + 당장 적용할 부분이 없음 / 더 읽어야 함 | 이유를 짧게 설명하고 다음 절·끝나는 지점·읽을 목적을 안내한다. 새 범위를 이 파일에 기록한다. |

4. 적용 후에는 실제 변경·검증 결과를 기록하고 다음 독서 범위를 안내한다.
5. **완독 확인은 사용자에게 읽었는지를 묻는 것이며 이해도 시험을 뜻하지 않는다.**
   회상 질문·지연 평가·이전 시나리오 재풀이를 진행 조건으로 삼지 않는다.
   사용자가 퀴즈나 개념 설명을 요청하면 그때 진행한다. 학습 스킬의 기본 절차보다 이 흐름을 우선한다.

2026-10-06 R1 적용을 마치고 다음 독서 범위를 §3.4로 지정했다. 다음 세션에서는 이 범위를 다 읽었는지 먼저 묻는다.
도구를 나눌지 묶을지는 적용에 필요한 설계 선택 후보이며 고정된 첫 퀴즈가 아니다.

## 전체 계획과 현재 검토 지점

[ROADMAP.md](ROADMAP.md)가 전체 계획의 기준이다. 이 파일에는 상세 설계를 중복하지 않는다.

- 합의한 순서: R1 뉴스 도구 반환 → R2 기사 근거 확보 → R3 리포트 개선 → R4 추가 조사·평가 → R5 대화형 확장.
- R1은 2026-10-06 완료했다(미커밋). 완료 근거는 [ROADMAP.md](ROADMAP.md) §4 체크리스트·검증 결과, 실행 순서와 코드는 [R1-PLAN.md](R1-PLAN.md)에 있다.
- 다음 구현 대상은 R2 기사 근거 확보다. 착수 전에 본문 확보 방식(공급자 제공 정보·HTTP 추출·브라우저)과 검색·읽기 도구 경계를 세부 설계한다.
- 일반 웹 검색은 R4 후보로 둔다. R1의 시도 로그로 SerpAPI `empty` 빈도를 볼 수 있게 됐다.
- R2 이후는 각 단계에 도달했을 때 세부 설계한다.
- 문서 구조 승인과 제품 구현 완료를 구분한다. 기존 퀴즈·독서 완료 확인을 다시 시작하지 않는다.

- **이 파일:** 현재 위치와 다음 행동만 갱신한다.
- **[ROADMAP.md](ROADMAP.md):** 단계 상태·완료 기준·검증 근거를 갱신한다.

  변경 파일·실제 검증 결과를 날짜별로 덧붙인다. 에이전트가 기록하며 별도 양식 작성은 요구하지 않는다.
- 매 세션 종료 또는 중요한 진도·결정 변경 시 기록한다. 읽음·설명을 들음·독립 적용·구현·검증은 구분한다.
- 과거 기록의 회상·전이 “미확인”은 관찰 이력일 뿐, 다음 독서나 적용을 막는 미완료 과제가 아니다.

- 기존 LangGraph Lab 진도는 [LAB-PROGRESS.md](../langgraph-labs/LAB-PROGRESS.md)를 따른다.
  다른 트랙의 진도를 덮어쓰거나 같은 기록을 중복 생성하지 않는다.
- 실제 Python 실행 시 [RESOURCES.md](../../RESOURCES.md)의 환경 주의사항을 확인한다.
  `uv run` 대신 프로젝트 `.venv/bin/python`을 사용한다.
